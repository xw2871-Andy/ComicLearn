# `samples/` — curated assets from the original ComicLearn / OpenClaw runs

These files were generated by Andy's pre-agent OpenClaw workspace over the
2025-2026 academic year while student-teaching AP Calculus AB. They are
shipped with the agent so you can:

1. See exactly what kind of output the pipeline is designed to produce.
2. Study the bundled reference comic pages with `--reference` to understand
   style-locking behavior from the original prototype.
3. Feed any of the pre-existing lesson plans into the agent with
   `c2c markdown samples/lesson_plans/...` to skip the topic-only generation.

## Recommended starter commands

> Note: some historical samples use pop-culture-inspired classroom prototype
> characters. For public deployments, use original characters, school mascots,
> or licensed reference art.

### Run the canonical "Limits" demo with locked style references

```bash
c2c topic "Introducing the Limit" --grade "AP Calculus AB" \
    --reference samples/references/doraemon_teach_limit_page1.png \
    --reference samples/references/doraemon_teach_limit_page2.png \
    --reference samples/references/doraemon_teach_limit_page3.png
```

### Render the Derivative unit straight from its pre-written lesson plan

```bash
c2c markdown samples/lesson_plans/Unit_2_Derivatives/2.1_Storyboard.md \
    --topic "Defining the Derivative" \
    --grade "AP Calculus AB" \
    --reference samples/references/derivative_style_ref1.png \
    --reference samples/references/derivative_style_ref2.png
```

### Inspect a known-good prior run

`samples/showcase/Unit_2.1_Derivative/` contains the storyboard markdown plus
the 6 final scene JPEGs from Andy's hand-run pipeline. Use it as a visual
target when iterating on prompts.

## How references work

When `IMAGE_BACKEND=gemini`, every `--reference` image is base64-embedded into
every Gemini Nano Banana 2 call as an `inlineData` part. Combined with the
rolling self-reference (the previous panel is also fed to the next call),
this anchors character designs, palette, and panel layout across all 6 scenes
of a comic.

References are **ignored** by the default `svg` backend (which has Claude
author the vector panels directly).
